Data Cleaning and Preparation¶

In [3]:
df["time"] = pd.to_datetime(df["properties.time"], unit="ms")
df = df.dropna(subset=["properties.mag"])

df["longitude"] = df["geometry.coordinates"].apply(lambda x: x[0] if isinstance(x, list) else None)
df["latitude"] = df["geometry.coordinates"].apply(lambda x: x[1] if isinstance(x, list) else None)
df["depth"] = df["geometry.coordinates"].apply(lambda x: x[2] if isinstance(x, list) and len(x) > 2 else None)

Database Test Queries¶

The following queries demonstrate how the earthquake data model can be validated within a MongoDB environment.

These queries validate filtering, sorting, and pattern matching capabilities within the database. They demonstrate that the data model supports analytical operations required for earthquake data exploration.

In [10]:
# MongoDB-style test queries (for report demonstration)

print("Query 1: Find earthquakes with magnitude > 5")
print('db.earthquakes.find({ "properties.mag": { $gt: 5 } })')

print("\nQuery 2: Sort by most recent earthquakes")
print('db.earthquakes.find().sort({ "properties.time": -1 }).limit(10)')

print("\nQuery 3: Search earthquakes in California")
print('db.earthquakes.find({ "properties.place": /California/i })')

print("\nQuery 4: Find earthquakes with tsunami risk")
print('db.earthquakes.find({ "properties.tsunami": 1 })')
